# Blink LED Project

## Description

The **Blink LED** project is a basic electronics and embedded systems project designed to demonstrate how a microcontroller can control an LED. The LED is programmed to turn **ON and OFF at regular time intervals**, creating a blinking effect.

This project helps beginners understand **digital output, GPIO pins, timing, programming logic, and basic hardware-software interfacing**.

## Objectives

* To understand basic microcontroller operation.
* To learn how to configure and control a digital output pin.
* To interface an LED with a microcontroller.
* To understand timing and delay functions.
* To gain practical experience in embedded programming.

## Components Required

* Microcontroller development board
* LED
* Resistor
* Breadboard
* Jumper wires
* USB cable
* Computer/Laptop

## Working Principle

The LED is connected to a digital output pin of the microcontroller through a resistor. The program configures the selected pin as an output and repeatedly performs the following operations:

1. Set the digital pin **HIGH** → LED turns ON.
2. Wait for a specified time.
3. Set the digital pin **LOW** → LED turns OFF.
4. Wait again.
5. Repeat the process continuously.
